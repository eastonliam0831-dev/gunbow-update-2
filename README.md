# Gun Bow (Minecraft Java 26.3, Fabric, client-side)

Pick one of 40 modeled guns from a menu and your **bow** becomes that gun:
model, hover/tooltip/held-item name, hold position and gunshot sound.
It is a pure client-side retexture of the vanilla bow - nothing is sent to the server,
so it works on any server. Only you see it.

* Open the menu: **G** (rebind under Options > Controls > Key Binds > Gun Bow)
* Pick a category tab, then a gun. **Vanilla Bow** turns it off. Your choice is saved to `config/gunbow.txt`.
* The menu shows a preview of the selected gun. Click a gun to equip it (and preview it).
* Gunshot sound plays when you release the bow with a real draw (same moment an arrow fires).
  Shotguns and snipers also cycle (pump / bolt) after each shot. Press **R** to play the gun's reload sound.
* Sounds are real recordings per class: pistol, revolver, SMG, rifle (assault rifle + bullpup), shotgun, sniper.
* Fire rate: the bow itself fires the arrow, so the real rate is however fast you can draw and release a bow.
  The mod does not auto-fire (that is server-visible and can get you banned).

Requires: Minecraft Java 26.3, Fabric Loader 0.19.5+, Fabric API, Java 25.

## Getting the .jar
1. Create a GitHub repo and push this folder to it.
2. Open the **Actions** tab -> the `build` run -> download the **gunbow-jar** artifact.
3. Unzip it and drop `gunbow-1.0.0.jar` into `.minecraft/mods` (with Fabric API).

Local build instead: install Java 25 + Gradle 9, run `gradle build`, jar is in `build/libs/`.

## Names
The Quaternius models are generic (Pistol 1-6, Revolver 1-5, ...), not specific real-world gun models,
so they are named exactly as the pack names them. Edit names in `tools/build_assets.py` (`gun_list()`)
and re-run it to regenerate `Guns.java`.

## Tuning hold positions / sounds
Everything under `src/main/resources/assets/gunbow` is generated by `tools/build_assets.py`
(`python3 tools/build_assets.py <path to Ultimate_Gun_Pack/OBJ>`; needs numpy, scipy, pillow, ffmpeg).
Hold transforms are in the `display()` function (first/third person rotation, translation, scale).
You can also edit the `display` block of any `models/item/<gun>.json` directly.
Sounds: `python3 tools/build_assets.py <OBJ dir> <sound source dir>` rebuilds `sounds/fire_<class>.ogg` / `reload_<class>.ogg` from your recordings (see `SOUND_SPEC`). Or just drop your own `.ogg` over those files.
